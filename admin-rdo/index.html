RDO móvel — área administrativa

Os RDOs e as fotos são armazenados no repositório privado RDO_CERTARE. Somente o administrador autorizado consegue consultar ou gravar dados.

Use um fine-grained personal access token limitado ao repositório privado RDO_CERTARE, com Contents e Pull requests (leitura e escrita). O token fica somente na memória da página: não é salvo no HTML, no dispositivo nem nas fotos.

O formulário só é habilitado depois da verificação da conta e da permissão de administrador pela API do GitHub. Esta página isolada não equivale a um sistema OAuth com sessão de servidor.
